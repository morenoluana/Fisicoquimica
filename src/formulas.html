1 · Gases

Gas ideal$P\cdot V = n\cdot R\cdot T$
Moles y masa$n = \dfrac{\text{masa}}{M}$
Cambio de estado (n cte)$\dfrac{P_i\cdot V_i}{T_i} = \dfrac{P_f\cdot V_f}{T_f}$V cte: P/T cte · P cte: V/T cte · T cte: P·V cte
Masa molar con densidad$M = \dfrac{\rho\cdot R\cdot T}{P}$
Dalton (mezcla de gases)$P_T = P_A + P_B + \dots$
$P_i = X_i\cdot P_T$
$X_i = \dfrac{n_i}{n_T}$
Factor de compresión$Z = \dfrac{P\cdot V}{n\cdot R\cdot T} = \dfrac{V_m}{V_{m,\,ideal}}$Z = 1 ideal · Z < 1 atracciones · Z > 1 repulsiones
Virial (en V)$Z = 1 + \dfrac{B}{V_m} + \dfrac{C}{V_m^2}$truncado: B = (Z − 1)·Vm · B < 0 atracciones, B > 0 repulsiones · T de Boyle: B = 0
Virial (en P) → moles$Z = 1 + B'\cdot P$
$n = \dfrac{P\cdot V}{R\cdot T\,(1 + B'\cdot P)}$B' ≈ B/(R·T) · B' en atm⁻¹ si P en atm
Van der Waals$P = \dfrac{n\cdot R\cdot T}{V - n\cdot b} - \dfrac{a\cdot n^2}{V^2}$a = atracciones · b = volumen excluido (repulsiones)
Van der Waals: despejar V$V = \dfrac{n\cdot R\cdot T}{P + a\,n^2/V^2} + n\cdot b$arrancá con V ideal y repetí hasta que no cambie
Punto crítico (VdW)$V_c = 3b \qquad P_c = \dfrac{a}{27\,b^2} \qquad T_c = \dfrac{8a}{27\,R\,b}$
Variables reducidas$P_r = \dfrac{P}{P_c} \qquad T_r = \dfrac{T}{T_c}$Pr ≪ 1 y Tr > 1 → casi ideal · cerca de 1 → real

2 · Primera ley y calorimetría

Primero: ¿qué es constante?V cte (rígido) → W = 0, q = ΔU · P cte → q = ΔH · aislado/adiabático → q = 0 · isotérmico, gas ideal → ΔU = ΔH = 0
Primera ley$\Delta U = q + W$lo que recibe el sistema es (+): expansión W < 0 · compresión W > 0
Trabajo contra P externa cte$W = -P_{ext}\cdot\Delta V$V cte (rígido) o contra vacío → W = 0
Isotérmico reversible, ideal$W = -n\cdot R\cdot T\cdot\ln\dfrac{V_f}{V_i} = -n\cdot R\cdot T\cdot\ln\dfrac{P_i}{P_f}$ΔU = 0 → q = −W · reversible = W máximo en expansión
Isotérmico reversible, VdW$W = -n\,R\,T\ln\dfrac{V_f - n\,b}{V_i - n\,b} - a\,n^2\left(\dfrac1{V_f} - \dfrac1{V_i}\right)$
Isotérmico reversible, virial$W = -n\,R\,T\left[\ln\dfrac{V_f}{V_i} + n\,B\left(\dfrac1{V_i} - \dfrac1{V_f}\right)\right]$
Entalpía$H = U + P\cdot V$
Calor a V cte$q_V = \Delta U = n\cdot C_v\cdot\Delta T$
Calor a P cte$q_P = \Delta H = n\cdot C_p\cdot\Delta T$
Cp y Cv (gas ideal)$C_v = C_p - R$monoatómico: Cv = 3/2 R, Cp = 5/2 R · diatómico: Cv = 5/2 R
Cp variable con T$C_p = a + b\cdot T + \dfrac{c}{T^2}$
$\Delta H = a\,(T_2 - T_1) + \dfrac b2\,(T_2^2 - T_1^2) - c\left(\dfrac1{T_2} - \dfrac1{T_1}\right)$
Adiabático reversible, ideal$q = 0 \qquad W = \Delta U = n\cdot C_v\cdot\Delta T$
$\dfrac{T_f}{T_i} = \left(\dfrac{V_i}{V_f}\right)^{R/C_v} \qquad P\cdot V^{\gamma} = \text{cte},\ \gamma = \dfrac{C_p}{C_v}$
Gas real (VdW) a V cte$\Delta H = \Delta U + V\cdot\Delta P$
$\Delta P = \dfrac{n\cdot R\cdot\Delta T}{V - n\cdot b}$
ΔU de VdW si cambia V$\Delta U = n\cdot C_v\cdot\Delta T - a\,n^2\left(\dfrac1{V_f} - \dfrac1{V_i}\right)$
Calorímetro$\sum q = 0$
$m_1 c_1 (T_f - T_1) + m_2 c_2 (T_f - T_2) + K_c (T_f - T_2) = 0$Kc = calor para subir 1 K el calorímetro · supuesto: aislado, c constante
Calorímetro con cambio de fase$q = m\cdot c\cdot\Delta T \quad + \quad m\cdot L$hielo: calentar → fundir (m·Lf) → calentar agua · vapor: condensar (m·Lv) → enfriar

3 · Termoquímica

Hess con formación$\Delta H^\circ = \sum\Delta H_f^\circ\ \text{productos} - \sum\Delta H_f^\circ\ \text{reactivos}$con coeficientes · elementos en su forma estable (O₂, H₂, C grafito) = 0
Hess con combustión$\Delta H^\circ = \sum\Delta H_c^\circ\ \text{reactivos} - \sum\Delta H_c^\circ\ \text{productos}$al revés que con formación
Energías de enlace$\Delta H^\circ = \sum E_{\text{rotos}} - \sum E_{\text{formados}}$solo enlaces que cambian · valores para gas · si sale H₂O(l), restar 44 kJ por mol de agua
ΔH y ΔU$\Delta U^\circ = \Delta H^\circ - \Delta n_g\cdot R\cdot T$Δng = moles de gas productos − reactivos (solo gases)
Kirchhoff (ΔH a otra T)$\Delta H_{T_2} = \Delta H_{T_1} + \Delta C_p\,(T_2 - T_1)$
$\Delta C_p = \sum C_p\ \text{productos} - \sum C_p\ \text{reactivos}$en ΔCp entran todos, también O₂, H₂ y C
Disolución iónica$\Delta H_{sol}^\circ = \sum\Delta H_f^\circ\ \text{iones (ac)} - \Delta H_f^\circ\ \text{sal (s)}$ΔHf°(H⁺, ac) = 0
Cambios de fase$\Delta H_{sub} = \Delta H_{fus} + \Delta H_{vap}$
$\Delta H_{vap} = -\Delta H_{cond}$
SignoΔH < 0 exotérmica (libera calor) · ΔH > 0 endotérmicaΔHf° = 0 solo en la forma más estable: grafito sí, diamante no (+1,9 kJ/mol) · en combustión el agua va líquida

4 · Segunda ley

Entropía de reacción$\Delta S^\circ = \sum S^\circ\ \text{productos} - \sum S^\circ\ \text{reactivos}$en J/K · S° de elementos ≠ 0
Entropía: definición y universo$dS = \dfrac{dq_{rev}}{T}$
$\Delta S_{univ} = \Delta S_{sis} + \Delta S_{ent} \ge 0 \qquad \Delta S_{ent} = -\dfrac{q_{sis}}{T}$
ΔS en cambio de fase$\Delta S = \dfrac{\Delta H_{tr}}{T_{tr}}$
ΔS al calentar$\Delta S = n\cdot C_p\cdot\ln\dfrac{T_2}{T_1}$
ΔS isotérmico, gas ideal$\Delta S = n\cdot R\cdot\ln\dfrac{V_2}{V_1}$
Gibbs$\Delta G^\circ = \Delta H^\circ - T\cdot\Delta S^\circ$
$\Delta G^\circ = \sum\Delta G_f^\circ\ \text{productos} - \sum\Delta G_f^\circ\ \text{reactivos}$T y P ctes: ΔG < 0 espontánea · ΔG = 0 equilibrio · ΔG > 0 no espontánea
Helmholtz$\Delta A = \Delta U - T\cdot\Delta S$T y V ctes: ΔA < 0 espontánea
Temperatura de inversión$T_{inv} = \dfrac{\Delta H}{\Delta S}$solo si ΔH y ΔS tienen el mismo signo
Trabajo máximo$W_{\text{máx útil}} = -\Delta G$ (T y P ctes)
$W_{\text{máx total}} = -\Delta A$ (T cte)
Calor de la reacción$q_P = \Delta H \qquad q_V = \Delta U$
ΔHΔS¿Espontánea?
−+siempre
+−nunca
−−a T bajas (T < Tinv)
++a T altas (T > Tinv)

5 · Equilibrio y electroquímica

Potencial químico$\mu_i = \mu_i^\circ + R\cdot T\cdot\ln a_i$sólidos y líquidos puros: a = 1
Avance de reacción$\xi = \dfrac{n_i - n_i^0}{\nu_i}$
ΔG fuera del equilibrio$\Delta G = \Delta G^\circ + R\cdot T\cdot\ln Q$Q < K → avanza a productos · Q > K → vuelve a reactivos · Q = K equilibrio
Constante de equilibrio$\Delta G^\circ = -R\cdot T\cdot\ln K$
$K = e^{-\Delta G^\circ/(R\cdot T)}$
Kp (gases)$K_p = \dfrac{\prod P\ \text{productos gaseosos}}{\prod P\ \text{reactivos gaseosos}}$cada P elevada a su coeficiente · sólidos no entran
Kp, Kc y Kx$K_p = K_c\,(R\cdot T)^{\Delta n_g}$ (R = 0,082)
$K_p = K_x\cdot P_T^{\Delta n_g}$
Van't Hoff (K con T)$\dfrac{d\ln K}{dT} = \dfrac{\Delta H^\circ}{R\,T^2}$
$\ln\dfrac{K_2}{K_1} = -\dfrac{\Delta H^\circ}{R}\left(\dfrac1{T_2} - \dfrac1{T_1}\right)$ΔH de la reacción (con coeficientes) · endo: K sube con T · exo: K baja
Le Chatelieragregar reactivo → derecha · subir P → lado con menos moles de gas · subir T → sentido endotérmico
Gibbs y potencial de celda$\Delta G^\circ = -n\cdot F\cdot E^\circ$
$E^\circ = -\dfrac{\Delta G^\circ}{n\cdot F}$n = moles de electrones · E > 0 espontánea
E° y K$E^\circ = \dfrac{R\cdot T}{n\cdot F}\ln K$
Nernst$E = E^\circ - \dfrac{R\cdot T}{n\cdot F}\ln Q = E^\circ - \dfrac{0{,}0592}{n}\log Q$ (25 °C)
Potencial de celda$E^\circ_{celda} = E^\circ_{cátodo} - E^\circ_{ánodo}$cátodo: reducción · ánodo: oxidación
Potencial electroquímico$\tilde\mu_i = \mu_i + z_i\cdot F\cdot\phi$
$\Delta G_{tr} = R\,T\ln\dfrac{a_i^\beta}{a_i^\alpha} + z_i\,F\,(\phi^\beta - \phi^\alpha)$
Procesos acoplados y bioquímicoK total = K₁ · K₂ (los ΔG° se suman)estándar bioquímico ΔG°′: pH 7, 37 °C

6 · Cambios de fase

Equilibrio entre fases$\mu^\alpha = \mu^\beta$la sustancia pasa de μ mayor a μ menor · dμ = −Sm·dT + Vm·dP
Regla de las fases$F = C - P + 2$un componente: F = 3 − P · punto triple: F = 0
Clapeyron (cualquier curva)$\dfrac{dP}{dT} = \dfrac{\Delta H}{T\cdot\Delta V_m}$
Sólido–líquido integrada$P_2 - P_1 = \dfrac{\Delta H_{fus}}{\Delta V_m}\ln\dfrac{T_2}{T_1}$
$\Delta H_{fus} = \dfrac{\Delta V_m\,(P_2 - P_1)}{\ln(T_2/T_1)}$ΔVm en m³/mol y P en Pa
ΔV con densidades$\Delta V_m = M\left(\dfrac1{\rho_{líq}} - \dfrac1{\rho_{sól}}\right)$
¿Sólido o líquido ocupa más?Tfusión normal > Ttriple → pendiente +, ΔV > 0 → sólido ocupa menos. Tfusión normal < Ttriple → pendiente −, como el agua → sólido ocupa más.
Clausius-Clapeyron (líq–vapor, sól–vapor)$\ln\dfrac{P_2}{P_1} = -\dfrac{\Delta H_{vap}}{R}\left(\dfrac1{T_2} - \dfrac1{T_1}\right)$sublimación: usar ΔHsub · supone gas ideal, Vgas ≫ Vlíq, ΔH cte
Despejar T₂$\dfrac1{T_2} = \dfrac1{T_1} - \dfrac{R}{\Delta H_{vap}}\ln\dfrac{P_2}{P_1}$
Despejar ΔH$\Delta H_{vap} = \dfrac{R\,\ln(P_2/P_1)}{1/T_1 - 1/T_2}$
Puntos de referenciaebullición normal: Pvap = 1 atm · el punto triple está sobre las 3 curvasarriba de Tc no se licúa · agua: 100 °C a 101,325 kPa, ΔHvap = 40,7 kJ/mol
Ehrenfest1.er orden: saltan H, S, V (fusión, vaporización) · 2.º orden: salta Cp · λ: Cp → ∞
