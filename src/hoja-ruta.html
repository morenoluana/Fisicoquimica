Hoja 1 = fórmulas · Hoja 2 = qué hacer con ellas

0Método para cualquier ejercicio

  1. Leé todo una vez sin calcular. Subrayá lo que piden (verbo + magnitud: "calcule w", "determine T").
  2. Listá los datos con unidades en columna. Marcá datos escondidos: "rígido", "aislado", "normal", "estándar", "elemental".
  3. Reconocé el tema con el diccionario de abajo: cada frase clave dice qué fórmula usar.
  4. Escribí las hipótesis (ideal/real, V o P cte, Cp cte, ΔH cte). Suman puntos aunque el número salga mal.
  5. Pasá a unidades coherentes antes de reemplazar: T en K, P y V con la R que corresponda, todo J o todo kJ.
  6. Escribí la fórmula general, después el despeje, después los números. Nunca números sueltos.
  7. Controlá: signo con sentido físico, orden de magnitud (tabla de la cara 2), unidades del resultado.
  8. Respondé con una frase: "ΔG° < 0, la reacción es espontánea a 298 K".
Estrategia de examen (180 min) 5 ejercicios × 20 % → ~30 min c/u y 30 min para revisar. Empezá por el que te sale seguro. Si te trabás 5 min, escribí planteo + hipótesis y seguí. Ítems encadenados: si no te sale el a), inventá un valor razonable ("supongo n = 1 mol") y resolvé el b). Bonus: solo si estás segura (los incorrectos no suman).

AÁrbol · ¿qué proceso es? (gas)

¿V cte? → W = 0, ΔU = q = nCvΔT · ideal: ΔH = nCpΔT · VdW: ΔH = ΔU + VΔP, Pf con VdW
¿q = 0? → ¿reversible? sí: $T_f = T_i\left(\frac{V_i}{V_f}\right)^{R/C_v}$, W = nCvΔT · no (contra Pext): $nC_v(T_f - T_i) = -P_{ext}(V_f - V_i)$ → despejá Tf
¿T cte? → ideal: ΔU = ΔH = 0 · reversible: W = −nRT ln(Vf/Vi) · contra Pext: W = −PextΔV
¿P cte? → W = −PΔV, q = ΔH = nCpΔT, ΔU = nCvΔT
¿Qué ecuación de estado?
dice "ideal" o P baja → PV = nRT · da a, b o "tolueno" → VdW · da B o B′ → virial · no dice nada y pide "comparar" → hacé las dos

BÁrbol · ¿qué tipo de solución?

  1. Solvente vs Raoult: calculá XA·PA* y comparalo con PA medida.
  2. Soluto: calculá PB/XB en cada punto. ¿Es igual a PB*? → Raoult. ¿Es constante pero ≠ PB*? → Henry (ese valor es KH).
  3. Los dos cumplen Raoult → ideal · solvente Raoult + soluto Henry → idealmente diluida · ninguno → real (usá actividades).
  4. Escribí μ: ideal y solvente → μ* + RT ln X · soluto Henry → μ° + RT ln X con estado de referencia de Henry · real → con γ.
Desvío chico (< 1–2 %) → decí "se aproxima a…, estrictamente es real". Desvío +: P mayor que Raoult (repulsión A–B); −: menor (atracción A–B).

DCaso integrador (formato del previo)

  1. Cada etapa es un tema: extracción / destilación → mezclas, Raoult, coligativas · operación térmica, reactor → 1.ª ley con gas real · síntesis → termoquímica + espontaneidad · almacenamiento, degradación → cinética · luz, electrones, "termina cuando" → equilibrio y E°.
  2. Los datos de una etapa se usan en esa etapa, salvo que diga "del punto anterior". Sobran datos: es normal.
  3. Si falta un dato (Cp, S°, a, b, ΔHf°), está en tus tablas. Si no, declaralo como supuesto y seguí.
  4. Cada pregunta vale 20 %: resolvelas en el orden que te convenga, no en el del enunciado.

R1Mezcla binaria del previo (sale siempre)

  1. Masas: kg solución × % m/m = soluto; resto = solvente. Pasá a moles con M.
  2. Molalidad m = nst/kgsolvente · X = ni/nT en el líquido.
  3. Vapor: PT = ΣPi → yi = Pi/PT. Si dan P* y PT: XA = (PT − PB*)/(PA* − PB*).
  4. Clasificar con el árbol B. Justificá con números (X·P* vs P medida; P/X constante).
  5. Si piden ebullición: ΔTb = Kb·m → Tb = Tb* + ΔTb.
✓ Luminurina: m = 0,414 mol/kg · XL = 0,042 · yEB = 0,971 · idealmente diluida · hexano–octano: Xhex = 0,211 · dic-22: XA = 0,972, yA = 0,949

R2Gas real en recipiente rígido / virial

  1. Rígido → W = 0 → q = ΔU. Hipótesis: Cv cte; en VdW el término a no cambia porque V es cte.
  2. ΔU = nCvΔT (Cv = Cp − R de tabla).
  3. V inicial: con VdW iterando (o ideal si la P es baja). Pf = nRTf/(V − nb) − an²/V².
  4. ΔH = ΔU + VΔP (VdW) · comparar con Pf,ideal = PiTf/Ti.
  5. Virial: n = PV/(RT(1 + B′P)) → masa = nM. B′ y P en unidades inversas (atm⁻¹ con atm).
✓ EB 1,5 mol 298→380 K: W = 0, q = ΔU ≈ +14,8 kJ, Pf ≈ 1,29 bar (ideal 1,32)

R3Adiabático y calorímetro

  1. Adiabático reversible: n = PV/RT → Tf = Ti(Vi/Vf)R/Cv → W = ΔU = nCvΔT (W < 0 si se expande).
  2. Adiabático contra Pext (H2S): W = −PextΔV → ΔU = W → ΔT → con VdW sumá el término a.
  3. Calorímetro: Σq = 0. Escribí un término por tramo: calentar sólido + fundir (+mLf) + calentar líquido; condensar (−mLv) + enfriar. Incógnita = masa → despejá.
✓ Neón 12→14 L: Tf = 269 K, W ≈ −534 J · H2S: W = +112 J, ΔH = 0, Tf ≈ 296 K · hielo + vapor: ≈ 41,5 g de vapor

R4Termoquímica completa + espontaneidad

  1. Balanceá y marcá estados. ΔH° por enlaces o por formación.
  2. ΔU° = ΔH° − ΔngRT (RT = 2,479 kJ/mol a 298 K).
  3. ΔH(T) = ΔH° + ΔCp(T − 298) con ΔCp = ΣνCp(prod) − ΣνCp(reac).
  4. ΔS° de tabla (J/K) → ΔG° = ΔH° − TΔS° con ΔS en kJ/K.
  5. T inversión = ΔH°/ΔS°. ¿Existe? Solo si ΔH y ΔS tienen el mismo signo.
  6. W útil máx = −ΔG° · W máx total = −ΔA = −(ΔU − TΔS) · calor = qP = ΔH.
✓ Luminurina: ΔH° ≈ −230, ΔU° ≈ −228, ΔH(398) ≈ −224 kJ/mol · ΔS° = −52,7 J/K · ΔG° ≈ −214 kJ/mol · Tinv ≈ 4360 K · N≡N = 942 kJ/mol · P4O10: ΔH° = 147,3, ΔU° = 177,0 kJ · HClO4: ΔH ≈ −90, ΔU ≈ −95 kJ/mol · butano: ΔU = −2868 kJ/mol · CO2 25→500 °C: ≈ 21,5 kJ/mol

R5Fases: Clapeyron y Clausius

  1. ¿V sólido o líquido?: con los datos, ¿la curva s–l va hacia T mayor o menor al subir P? Si Ptriple < 1 atm y Tfusión normal < Ttriple → pendiente negativa → ΔVfus < 0 → sólido ocupa más (como el agua).
  2. ΔHfus = ΔV(P2 − P1)/ln(T2/T1) con dos puntos de la curva (triple y fusión normal). ΔV en m³/mol, P en Pa.
  3. Olla / ebullición a otra P: 1/T2 = 1/T1 − (R/ΔHvap) ln(P2/P1) con (101,325 kPa; 373,15 K), ΔHvap = 40,7 kJ/mol.
  4. Explicar la olla: P mayor → T de ebullición mayor → k mayor (Arrhenius) → cocina más rápido.
✓ olla 200 kPa ≈ 394 K (121 °C) · 120 kPa ≈ 378 K · sólido vs líquido (Tf 300 < Tt 330 K): sólido ocupa más · Urquidato: sublimación ≈ 27,6 Pa

R6Coligativas

  1. De % m/m: masa soluto y solvente → m = nst/kgste → ΔT = K·m.
  2. De π: c = π/(RT) con π en Pa → mol/m³ → ÷1000 = mol/L ≈ mol/kg (agua, diluida) → ΔTF.
  3. Masa molar: M = K·masast/(ΔT·kgste). Electrolitos: × i.
✓ π = 120 kPa a 300 K: c = 48,1 mol/m³ → ΔTF = 0,089 K → TF = 273,06 K

R7Cinética

  1. Orden: elemental → coeficiente · t½ vs [A]0 · tabla → ln[A] y 1/[A] vs t.
  2. k: orden 1 k = ln(C0/C)/t = ln2/t½ · orden 2 k = 1/(t½[A]0).
  3. Tiempo hasta C: t = ln(C0/C)/k. Atajo con dos datos: $t_C = t_1\,\frac{\ln(C_0/C)}{\ln(C_0/C_1)}$ (sin calcular k).
  4. Varias vidas medias: C = C0(½)N → ¼ = 2 t½, ⅛ = 3 t½.
  5. Ea con k a dos T; T con Ea y A: T = Ea/(R ln(A/k)).

  2. n = ΔP·V/(RT) en el espacio de cabeza.

R10Cómo encarar un "deduzca"

  1. Escribí la definición o ley de partida (ley de velocidad, G = H − TS, μα = μβ).
  2. Pasá a forma diferencial y separá variables.
  3. Integrá con límites (t = 0 → t, [A]0 → [A]).
  4. Aplicá la condición particular (t½: [A] = [A]0/2; equilibrio: ΔG = 0).
  5. Recuadrá el resultado y escribí cuándo vale (orden n ≠ 1, ΔH cte, gas ideal…).

TTeoría corta que toman (respuesta modelo)

Racional vs práctico
Racional: referencia líquido puro (Raoult), a = P/P*, γ → 1 si X → 1; para el solvente. Práctico: referencia Henry, a = P/KH, γ → 1 si X → 0; para el soluto. Los dos se usan para describir sistemas reales (γ mide el desvío del ideal).
μ de un disolvente real
μ = μ* + RT ln a, a = γX. Actividad = "concentración efectiva"; γ = coeficiente de actividad = a/X (1 en el ideal).
Coeficientes del virial
B mide interacciones entre pares de moléculas, C entre tríos. B < 0 dominan atracciones, B > 0 repulsiones; en la T de Boyle B = 0.
VdW (múltiple choice)
a/Vm² = atracciones; (Vm − b) = repulsiones (volumen excluido). La opción "a = repulsión, b = atracción" es falsa.
ΔU = 0 cuando ΔT = 0
Solo para gases ideales (U depende solo de T). En gases reales hay término de interacciones.
Utilidad de Kirchhoff
Calcular ΔH de reacción a una T distinta de la de tabla (298 K) usando ΔCp. Caso resuelto: R9.
Diamante vs grafito
ΔHf° = 0 solo para el elemento en su forma más estable a 1 bar y 298 K (grafito). El diamante es otra forma alotrópica, menos estable: ΔHf° = +1,9 kJ/mol.
¿Cuándo orden = coeficiente?
Solo en reacciones elementales (ocurren en un paso; orden = molecularidad). En general el orden es experimental.
Ec. fundamental
dG = −SdT + VdP + Σμidni: incorpora la composición (ni) mediante el potencial químico.
K vs T
Van't Hoff: d ln K/dT = ΔH°/(RT²). Endotérmica: K sube con T; exotérmica: K baja.
Agua ligada
Interactúa con solutos y biopolímeros; movilidad restringida, no congela (hasta ≈ −40 °C), no se elimina por secado, no actúa como solvente.
Humedad de monocapa
Una molécula de agua por cada grupo polar; punto de máxima estabilidad del alimento (por encima, el agua es solvente y aceleran el deterioro y Maillard).
Geles: formación
Red 3D que retiene líquido. Se forman por enfriamiento (gelatina), evaporación, agregado de solventes o de electrolitos en exceso, cambio de pH. Imbibición: absorbe y se hincha; sinéresis: expulsa líquido.
Coloides hidrófilos vs hidrófobos
Hidrófilos: afinidad con el agua, aumentan viscosidad, poco sensibles a electrolitos (salvo en exceso), al perder agua forman geles. Hidrófobos: poca afinidad, no cambian viscosidad, muy sensibles a electrolitos (coagulan); se protegen con coloides protectores o tensioactivos.
