1Gases ideales y reales

Gas ideal
$P\,V = n\,R\,T \qquad n = \dfrac{\text{masa}}{M}$
$\dfrac{P_i V_i}{T_i} = \dfrac{P_f V_f}{T_f}$ (n cte) · $M = \dfrac{\rho\,R\,T}{P}$
Dalton (mezcla de gases)
$P_T = \sum P_i \qquad P_i = X_i\,P_T \qquad X_i = \dfrac{n_i}{n_T}$
Factor de compresión
$Z = \dfrac{P\,V}{n\,R\,T} = \dfrac{V_m}{V_{m,\,ideal}}$
Z < 1 atracciones · Z > 1 repulsiones · "Vm 12 % menor que el ideal" → Z = 0,88
Virial
$Z = 1 + \dfrac{B}{V_m} + \dfrac{C}{V_m^2} \qquad Z = 1 + B'\,P$
→ $B = (Z-1)\,V_m$ · $B' = \dfrac{Z-1}{P}$ · $B' \approx \dfrac{B}{R\,T}$ · moles: $n = \dfrac{P\,V}{R\,T\,(1 + B'P)}$ → masa = n·M
B < 0 atracciones · B > 0 repulsiones · T de Boyle: B = 0 · B' en atm⁻¹ si P en atm
Van der Waals
$\left(P + \dfrac{a\,n^2}{V^2}\right)(V - n\,b) = n\,R\,T$
→ $P = \dfrac{nRT}{V - nb} - \dfrac{an^2}{V^2}$ · → V: $V_0 = \dfrac{nRT}{P}$ e iterá $V = \dfrac{nRT}{P + an^2/V^2} + nb$
a corrige atracciones · b volumen excluido (repulsiones) · a en L²·atm/mol², b en L/mol
¿Ideal o real? · punto crítico
$P_r = \dfrac{P}{P_c}$, $T_r = \dfrac{T}{T_c}$ (de tabla): Pr ≪ 1 y Tr > 1 → casi ideal · VdW: $V_c = 3b$, $P_c = \frac{a}{27b^2}$, $T_c = \frac{8a}{27Rb}$

2Capacidades caloríficas · calorimetría

Cp, Cv
$C_v = \left(\dfrac{\partial U}{\partial T}\right)_V \quad C_p = \left(\dfrac{\partial H}{\partial T}\right)_P \quad C_{p,m} - C_{v,m} = R$
monoatómico Cv = 3/2 R, Cp = 5/2 R · diatómico 5/2 R y 7/2 R (D4)
Cp variable: $C_p = a + bT + c/T^2$
$\Delta H = a\,(T_2 - T_1) + \dfrac b2\,(T_2^2 - T_1^2) - c\left(\dfrac1{T_2} - \dfrac1{T_1}\right)$
"Cp no es constante" → esta integral (a, b, c de tabla) · da qP por mol
Calorimetría
$\sum q_i = 0 \qquad q = m\,c\,(T_f - T_i) \qquad q_{fase} = \pm\, m\,L$
calorímetro: $q_{cal} = K_c\,(T_f - T_i)$ · $K_c$ = calor para subir 1 K el calorímetro
  1. Calorímetro: cada cuerpo con su T inicial; Tf común. El calorímetro arranca a la T de lo que contiene.
  2. Un término por tramo: calentar sólido → fundir ($+mL_f$) → calentar líquido · vapor: condensar ($-mL_v$) → enfriar.
  3. Σq = 0 con $(T_f - T_i)$ (el signo sale solo) → despejá. Control: Tf entre la mínima y la máxima.

3Termoquímica

$\Delta H^\circ = \sum \nu_p\,\Delta H_f^\circ(\text{prod}) - \sum \nu_r\,\Delta H_f^\circ(\text{reac})$
con combustión (al revés): $\Delta H^\circ = \sum\nu_r\,\Delta H_c^\circ(\text{reac}) - \sum\nu_p\,\Delta H_c^\circ(\text{prod})$
invertir la reacción cambia el signo · multiplicarla multiplica ΔH · ΔHf° es para formar 1 mol
Energías de enlace (gas)
$\Delta H^\circ = \sum n_i\,E_e(\text{rotos}) - \sum n_j\,E_e(\text{formados})$
solo los enlaces que cambian · un doble enlace es uno solo con su propia E · si sale H₂O(l): restá 44 kJ por mol de agua
Ee de la cátedra (kJ/mol) · usá la del examen si te la dan

ΔH ↔ ΔU
$\Delta U = \Delta H - \Delta n_g\,R\,T$
Δng = moles de gas productos − reactivos · con R = 8,314·10⁻³ kJ/(mol·K)
Kirchhoff (ΔH a otra T)
$\Delta H_{T_2} = \Delta H_{T_1} + \Delta C_p\,(T_2 - T_1)$
$\Delta C_p = \sum\nu_p\,C_{p}(\text{prod}) - \sum\nu_r\,C_{p}(\text{reac})$ · en J/K → ÷1000
en ΔCp entran todos, también O₂, H₂, C · supone Cp cte en el intervalo
Disolución · cambios de fase · alótropos
$\Delta H_{sol}^\circ = \sum\Delta H_f^\circ(\text{iones, ac}) - \Delta H_f^\circ(\text{sal, s})$, $\Delta H_f^\circ(\mathrm{H^+}) = 0$ · $\Delta H_{sub} = \Delta H_{fus} + \Delta H_{vap}$
ΔHf° = 0 solo para la forma más estable: grafito sí, diamante no (+1,9 kJ/mol) · en combustión el agua va líquida
  1. ΔH° de reacción: balanceá; mirá el estado (g/l/s) de cada especie.
  2. ΔHf° de tabla × coeficiente (elementos = 0) → productos − reactivos. "Por mol de X": ÷ coef. de X.
  3. ¿ΔU? Restá ΔngRT. ¿Otra T? Kirchhoff. ¿ΔG? Pasá a la sección 4.

4Segunda ley · espontaneidad

Entropía
$\Delta S^\circ = \sum\nu_p\,S^\circ(\text{prod}) - \sum\nu_r\,S^\circ(\text{reac})$
$dS = \frac{dq_{rev}}{T}$ · fase: $\Delta S = \frac{\Delta H_{tr}}{T_{tr}}$ · calentar: $\Delta S = nC_p\ln\frac{T_2}{T_1}$ · isotérmico ideal: $\Delta S = nR\ln\frac{V_2}{V_1}$
$\Delta S_{univ} = \Delta S_{sis} + \Delta S_{ent} \ge 0$, $\Delta S_{ent} = -\frac{\Delta H_{sis}}{T}$ · 3.ª ley: S = 0 a 0 K
Gibbs y Helmholtz
$\Delta G = \Delta H - T\,\Delta S \qquad \Delta A = \Delta U - T\,\Delta S$
$\Delta G^\circ = \sum\nu_p\,\Delta G_f^\circ - \sum\nu_r\,\Delta G_f^\circ$ · T de inversión: $T = \dfrac{\Delta H}{\Delta S}$ (ΔH y ΔS con el mismo signo)
T y P ctes → ΔG < 0 · T y V ctes → ΔA < 0 · ¡ΔS a kJ/K!
Trabajo máximo
$W_{\text{máx útil}} = -\Delta G\ \ (T, P\ \text{ctes}) \qquad W_{\text{máx total}} = -\Delta A\ \ (T\ \text{cte})$
lo que el sistema puede entregar · diapositiva: $(-\Delta A)_T = -w_{max}$, $(-\Delta G)_{T,p} = -w'_{max}$ (signo IUPAC) · una diapositiva escribe ΔG = ΔH + TΔS: es un error
ΔHΔS¿Espontánea?
−+siempre
+−nunca (cambiar T no sirve)
−−a T bajas: T < ΔH/ΔS
++a T altas: T > ΔH/ΔS

5Equilibrio químico

ΔG, Q y K
$\Delta G = \Delta G^\circ + R\,T\ln Q \qquad \Delta G^\circ = -R\,T\ln K$
→ $K = e^{-\Delta G^\circ/(R\,T)}$ · $Q = \dfrac{\prod a_{prod}^{\nu}}{\prod a_{reac}^{\nu}}$ (gas: P en atm; soluto: M; sólido o líquido puro: 1)
Q < K → avanza a productos · Q > K → vuelve · K ≫ 1 predominan productos, K ≪ 1 reactivos
Kp, Kc, Kx
$K_p = K_c\,(RT)^{\Delta n_g}$ (R = 0,08206) · $K_p = K_x\,P_T^{\Delta n_g}$ · duplicar la ecuación: K² · invertirla: 1/K
Van't Hoff (K con T)
$\ln\dfrac{K_2}{K_1} = -\dfrac{\Delta H^\circ}{R}\left(\dfrac1{T_2} - \dfrac1{T_1}\right)$
→ $\Delta H^\circ = -\dfrac{R\,\ln(K_2/K_1)}{1/T_2 - 1/T_1}$ · → $\dfrac1{T_2} = \dfrac1{T_1} - \dfrac{R}{\Delta H^\circ}\ln\dfrac{K_2}{K_1}$
ΔH° de la reacción (con coeficientes) · endo: K sube con T · exo: baja · supone ΔH° cte · Le Chatelier: +reactivo → derecha; ↑P → menos moles de gas; ↑T → sentido endo
De proporciones a presiones (tabla ICE)
A(g) → B(g) + C(s): $P_A = P_0 - x$, $P_B = x$ · "termina cuando $P_A = \tfrac13 P_B$" → $K_p = \dfrac{P_B}{P_A} = 3$ · si es A → 2B: $P_T = P_0 + x$
manómetro: el aumento de PT es el gas producido → n = P·V/(R·T)
Electroquímica
$\Delta G = -n\,F\,E \qquad E^\circ = \dfrac{R\,T}{n\,F}\ln K$
→ $E^\circ = -\dfrac{\Delta G^\circ}{n\,F}$ · Nernst: $E = E^\circ - \dfrac{R\,T}{n\,F}\ln Q = E^\circ - \dfrac{0{,}0592}{n}\log Q$
n = moles de e⁻ · $E^\circ_{celda} = E^\circ_{cát} - E^\circ_{án}$ (cátodo reduce) · diapositivas: E se escribe Δφ · ΔG en J

6Equilibrio de fases

Potencial químico y fases
$\mu^\alpha = \mu^\beta \qquad d\mu = -S_m\,dT + V_m\,dP$
pasa de μ mayor a μ menor (fase estable: menor μ) · ecuación fundamental: $dG = V\,dP - S\,dT + \sum\mu_i\,dn_i$ (agrega la composición)
Regla de las fases (D11)
$F = C - P + 2$
un componente: F = 3 − P · 1 fase: F = 2 · curva: F = 1 · punto triple: F = 0
Clapeyron (D9) · sólido–líquido
$\dfrac{dP}{dT} = \dfrac{\Delta S}{\Delta V} = \dfrac{\Delta H}{T\,\Delta V_m}$
integrada: $P_2 - P_1 = \dfrac{\Delta H_{fus}}{\Delta V_m}\ln\dfrac{T_2}{T_1}$ → $\Delta H_{fus} = \dfrac{\Delta V_m\,(P_2 - P_1)}{\ln(T_2/T_1)}$
$\Delta V_m = M\left(\dfrac1{\rho_{líq}} - \dfrac1{\rho_{sól}}\right)$ · ΔVm en m³/mol y P en Pa → ΔH en J/mol
¿Sólido o líquido ocupa más? Punto triple (Tt) y fusión normal (Tf, 1 atm): si Tf > Tt la pendiente es +, ΔVfus > 0 → el sólido ocupa menos. Si Tf < Tt, pendiente − (como el agua) → el sólido ocupa más. Justificá con Clapeyron: ΔHfus > 0 siempre.
Clausius-Clapeyron (D10) · líq–vap y sól–vap
$\ln\dfrac{P_2}{P_1} = -\dfrac{\Delta H_{vap}}{R}\left(\dfrac1{T_2} - \dfrac1{T_1}\right)$
→ $\dfrac1{T_2} = \dfrac1{T_1} - \dfrac{R}{\Delta H_{vap}}\ln\dfrac{P_2}{P_1}$ · → $P_2 = P_1\,e^{-\frac{\Delta H}{R}\left(\frac1{T_2} - \frac1{T_1}\right)}$
→ $\Delta H_{vap} = \dfrac{R\,\ln(P_2/P_1)}{1/T_1 - 1/T_2}$ (con 2 puntos) · sublimación: usá ΔHsub = ΔHfus + ΔHvap
supone gas ideal, $V_{gas} \gg V_{líq}$, ΔH cte · P en cualquier unidad · el punto triple sirve de punto 1 · ebullición normal: Pvap = 1 atm · agua: 373,15 K, ΔHvap = 2,26·10⁶ J/kg = 40,7 kJ/mol · olla: ↑P → ↑Teb → ↑k

7Mezclas · Raoult y Henry

Raoult (solvente o ideal) · Henry (soluto)
$P_i = X_i\,P_i^* \qquad P_{soluto} = K_H\,X_{soluto}$
$P_T = P_A + P_B$ · vapor: $y_A = \dfrac{P_A}{P_T}$ · binaria ideal: $X_A = \dfrac{P_T - P_B^*}{P_A^* - P_B^*}$, $y_A = \dfrac{X_A\,P_A^*}{P_T}$
X = fracción molar en el líquido · y = en el vapor · KH = pendiente de P vs X cuando X → 0 (≠ P*)
  1. ¿Ideal o idealmente diluida? Calculá Pi/Xi con los datos.
  2. Si los dos dan su P* → ideal (Raoult en todo el rango).
  3. Solvente = P* y soluto = constante ≠ P* → idealmente diluida (soluto en Henry).
  4. Ninguna constante → real: usá actividades.

7Potencial químico · coligativas

Potencial químico
$\mu_i = \left(\dfrac{\partial G}{\partial n_i}\right)_{T,P,n_j} \qquad G = \sum n_i\,\mu_i$
gas ideal (D12): $\mu = \mu^\circ + R\,T\ln\dfrac{P}{P^\circ}$ · solución ideal: $\mu_i = \mu_i^* + R\,T\ln X_i$ · real: $\mu_i = \mu_i^* + R\,T\ln a_i$
Gibbs-Duhem (D13): $\sum n_i\,d\mu_i = 0$ → $X_A\,d\ln a_A + X_B\,d\ln a_B = 0$
Actividad y coeficiente de actividad
$a_i = \gamma_i\,X_i$
racional (solvente, ref. líquido puro, Raoult): $a = \dfrac{P}{P^*}$, γ → 1 si X → 1 · práctico (soluto, ref. diluida, Henry): $a = \dfrac{P}{K_H}$, γ → 1 si X → 0
los dos son para sistemas reales; γ mide cuánto se aparta del modelo ideal · también escalas de molalidad y molaridad · bioquímico (ΔG°′): pH 7, 37 °C
Mezcla ideal
$\Delta G_{mez} = n\,R\,T\sum X_i\ln X_i \qquad \Delta H_{mez} = 0 \quad \Delta V_{mez} = 0$
gases a distinta P: $\Delta G_{mez} = R\,T\sum n_i\ln\dfrac{P_{i,final}}{P_{i,inicial}}$ (P final con el V total) · $\Delta\mu_A = R\,T\ln X_A$
Coligativas (soluto no volátil, solución diluida)
$\Delta P = X_{soluto}\,P_A^* \qquad \Delta T_b = K_b\,m \qquad \Delta T_F = K_F\,m \qquad \pi = C\,R\,T$
$T_b = T_b^* + \Delta T_b$ · $T_F = T_F^* - \Delta T_F$ · $K = \dfrac{R\,(T^*)^2\,M_A}{\Delta H}$ (MA en kg/mol; ΔHvap para Kb, ΔHfus para KF)
masa molar: $M = \dfrac{K_F\,\text{masa}_{sto}}{\Delta T_F\,\text{kg}_{ste}}$ · $M = \dfrac{\text{masa}\,R\,T}{\pi\,V}$ · electrolitos: × i
agua: KF = 1,86 · Kb = 0,51 K·kg/mol · π: C en mol/m³ con R = 8,314 → Pa; C en M con 0,08206 → atm
Molalidad o molaridad ΔTb, ΔTF → molalidad m (mol soluto/kg solvente; no depende de T). π → molaridad C. En agua diluida m ≈ C. Con % m/m: masa soluto = %·masa total; kg solvente = el resto.

  7. con $[A] = [A]_0/2$: $t_{1/2} = \dfrac{4\sqrt{[A]_0}}{k}\left(1 - \tfrac1{\sqrt2}\right) = \dfrac{(4 - 2\sqrt2)\sqrt{[A]_0}}{k}$ si se toma $-d[A]/dt = k[A]^{1/2}$ queda $(2-\sqrt2)\sqrt{[A]_0}/k$: aclarar cuál usás
D2 · Leyes integradas de orden 0, 1 y 2
  1. orden 0: $d[A] = -k\,dt \Rightarrow [A] = [A]_0 - kt$ → $t_{1/2} = \frac{[A]_0}{2k}$
  2. orden 1: $\frac{d[A]}{[A]} = -k\,dt \Rightarrow \ln\frac{[A]}{[A]_0} = -kt$ → $t_{1/2} = \frac{\ln 2}{k}$
  3. orden 2: $\frac{d[A]}{[A]^2} = -k\,dt \Rightarrow \frac1{[A]} - \frac1{[A]_0} = kt$ → $t_{1/2} = \frac1{k[A]_0}$
D3 · W isotérmico reversible (ideal y VdW)
  1. $dW = -P_{ext}\,dV$; reversible → $P_{ext} = P$ en cada paso
  2. ideal: $P = \dfrac{nRT}{V}$ → $W = -\displaystyle\int_{V_i}^{V_f}\frac{nRT}{V}dV = -nRT\ln\frac{V_f}{V_i} = -nRT\ln\frac{P_i}{P_f}$
  3. VdW: $W = -\displaystyle\int\left(\frac{nRT}{V - nb} - \frac{an^2}{V^2}\right)dV = -nRT\ln\frac{V_f - nb}{V_i - nb} - an^2\left(\frac1{V_f} - \frac1{V_i}\right)$
D4 · qP = ΔH y Cp − Cv = R
  1. $H = U + PV \Rightarrow dH = dU + P\,dV + V\,dP$; con $dU = dq - P\,dV$: $dH = dq + V\,dP$ → P cte: $dH = dq_P$
  2. gas ideal: $H = U + nRT \Rightarrow dH = dU + nR\,dT \Rightarrow C_p\,dT = C_v\,dT + nR\,dT \Rightarrow C_p - C_v = nR$
D5 · ΔH = ΔU + ΔngRT · D6 · Kirchhoff
  1. $\Delta H = \Delta U + \Delta(PV)$; sól./líq. ΔV ≈ 0; gases $PV = nRT$ → T cte: $\Delta(PV) = \Delta n_g RT$
  2. $\left(\frac{\partial\Delta H}{\partial T}\right)_P = \Delta C_p \Rightarrow \Delta H_{T_2} = \Delta H_{T_1} + \int_{T_1}^{T_2}\Delta C_p\,dT$
D7 · Criterio ΔG ≤ 0 y Wmáx
  1. $\Delta S_{univ} = \Delta S + \Delta S_{ent} \ge 0$, $\Delta S_{ent} = -\frac{\Delta H}{T}$ → × (−T): $\Delta H - T\Delta S = \Delta G \le 0$
  2. $G = H - TS$, reversible ($dq = T dS$), T y P ctes: $dG = dW'$ → $(-\Delta G)_{T,P} = W'_{máx\,entregado}$; igual $(-\Delta A)_T = W_{máx}$
D8 · ΔG° = −RT ln K · Van't Hoff · Nernst
  1. $\Delta G = \sum\nu_i\mu_i = \sum\nu_i\mu_i^\circ + RT\sum\nu_i\ln a_i = \Delta G^\circ + RT\ln Q$
  2. equilibrio: $\Delta G = 0$, $Q = K$ → $\Delta G^\circ = -RT\ln K$
  3. $\ln K = -\dfrac{\Delta G^\circ}{RT}$; Gibbs-Helmholtz $\dfrac{d(\Delta G^\circ/T)}{dT} = -\dfrac{\Delta H^\circ}{T^2}$ → $\dfrac{d\ln K}{dT} = \dfrac{\Delta H^\circ}{RT^2}$
  4. separar e integrar con ΔH° cte: $\displaystyle\int d\ln K = \frac{\Delta H^\circ}{R}\int\frac{dT}{T^2}$ → $\ln\dfrac{K_2}{K_1} = -\dfrac{\Delta H^\circ}{R}\left(\dfrac1{T_2} - \dfrac1{T_1}\right)$
  5. W eléctrico = −ΔG: $\Delta G = -nFE$ → $-nFE = -nFE^\circ + RT\ln Q$ → $E = E^\circ - \dfrac{RT}{nF}\ln Q$
D9 · Clapeyron · D10 · Clausius-Clapeyron
  1. sobre la curva $\mu^\alpha = \mu^\beta$ → $d\mu^\alpha = d\mu^\beta$: $-S^\alpha dT + V^\alpha dP = -S^\beta dT + V^\beta dP$
  2. $(V^\beta - V^\alpha)\,dP = (S^\beta - S^\alpha)\,dT$ → $\dfrac{dP}{dT} = \dfrac{\Delta S}{\Delta V}$; en equilibrio $\Delta S = \dfrac{\Delta H}{T}$ → $\dfrac{dP}{dT} = \dfrac{\Delta H}{T\,\Delta V}$
  3. s–l: $dP = \dfrac{\Delta H}{\Delta V}\dfrac{dT}{T}$ → $P_2 - P_1 = \dfrac{\Delta H}{\Delta V}\ln\dfrac{T_2}{T_1}$
  4. l–g: $\Delta V \approx V_{gas} = \dfrac{RT}{P}$ → $\dfrac{dP}{dT} = \dfrac{\Delta H\,P}{RT^2}$ → $\dfrac{dP}{P} = \dfrac{\Delta H}{R}\dfrac{dT}{T^2}$
  5. integrar (ΔH cte): $\ln\dfrac{P_2}{P_1} = -\dfrac{\Delta H}{R}\left(\dfrac1{T_2} - \dfrac1{T_1}\right)$
D11 · Regla de las fases
  1. variables: T, P y (C − 1) fracciones por fase: $P(C-1) + 2$ · restricciones: μ de cada componente igual en las P fases: $C(P-1)$
  2. $F = P(C-1) + 2 - C(P-1) = C - P + 2$
D12 · μ del gas ideal y de la solución · D13 · Gibbs-Duhem
  1. $\left(\dfrac{\partial G_m}{\partial P}\right)_T = V_m = \dfrac{RT}{P}$ → $\mu - \mu^\circ = \displaystyle\int_{P^\circ}^{P}\frac{RT}{P}dP = RT\ln\frac{P}{P^\circ}$
  2. solución: $\mu_i^{liq} = \mu_i^{vap} = \mu_i^\circ + RT\ln P_i$ con $P_i = X_iP_i^*$ → $\mu_i = \underbrace{\mu_i^\circ + RT\ln P_i^*}_{\mu_i^*} + RT\ln X_i$
  3. $G = \sum n_i\mu_i \Rightarrow dG = \sum\mu_i dn_i + \sum n_i d\mu_i$; a T, P ctes $dG = \sum\mu_i dn_i$ → $\sum n_i\,d\mu_i = 0$
D14 · ΔP y presión osmótica (van't Hoff)
  1. $\Delta P = P_A^* - X_AP_A^* = P_A^*(1 - X_A) = X_{sto}\,P_A^*$
  2. equilibrio: $\mu_A(\text{sol}, P + \pi) = \mu_A^*(P)$ → $\mu_A^*(P + \pi) + RT\ln X_A = \mu_A^*(P)$
  3. $\mu_A^*(P + \pi) - \mu_A^*(P) = \displaystyle\int_P^{P+\pi}V_m\,dP = V_m\,\pi = -RT\ln X_A$
  4. diluida: $-\ln X_A = -\ln(1 - X_{sto}) \approx X_{sto} \approx \dfrac{n_{sto}}{n_A}$ → $\pi\,V = n_{sto}RT$ → $\pi = C\,R\,T$
